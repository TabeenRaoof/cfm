# Sources

Every primary source consulted for a requirement, with the date it was actually opened and read.

A citation without a retrieval date is not a citation: the registry pages, guidance notes and
marketplace help articles behind these requirements change without notice or version history,
and "I read this on 12 September 2026" is the only claim we can stand behind later.

## How to use this file

One row per source, appended, never rewritten. When a source is re-checked, add a new row rather
than editing the old date — the history of when we last looked is what tells us which
requirements have gone stale.

   operator, for manufacturer identification, for technical documentation and risk analysis,
   and for the distance-selling information duties. Four requirements depend on these.
2. **PPWR** — Regulation (EU) 2025/40. Confirm Art. 44 (producer registration per member state)

4. **Germany** — VerpackG, LUCID registration and the dual-system obligation.
5. **France** — Code de l'environnement, the identifiant unique, and the Triman / Info-tri
   marking rules.

7. **UK** — the GB regime. Currently `confidence: low` and the least worked-through of the set.

Amazon and bol.com help pages are secondary sources: fine for channel mappings, never for what
the law requires.
